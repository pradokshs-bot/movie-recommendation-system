# 🎬 Movie Recommendation System

## 📌 Project Overview
The Movie Recommendation System is a Machine Learning project that recommends movies based on user preferences, movie genres, and ratings.

The project implements two recommendation techniques:
- **Content-Based Filtering:** Recommends movies with similar genres and characteristics.
- **Collaborative Filtering:** Recommends movies based on user ratings and similarities between movie preferences.

## 🎯 Objectives
- Build a simple movie recommendation system.
- Understand recommendation system algorithms.
- Implement Content-Based Filtering.
- Implement Collaborative Filtering.
- Generate personalized movie recommendations.

## 📂 Dataset
**MovieLens Latest Small Dataset**

Source: https://grouplens.org/datasets/movielens/latest/

The dataset contains movie information, genres, user IDs, and ratings.

## ⚙️ Project Implementation
1. Data Collection
2. Data Preprocessing

5. Collaborative Filtering
6. Movie Recommendation Generation

## 🚀 How to Run
1. Download or clone this repository.
2. Open the `.ipynb` notebook in Google Colab.
3. Download the MovieLens Latest Small dataset using the notebook cells.
4. Run all cells sequentially.
5. Test recommendations using different movie titles and user IDs.

## 📊 Expected Results
- Movie recommendations based on similar genres.
- Personalized movie recommendations based on user ratings.
- Comparison of two recommendation techniques.
